# Research notes

The raw notes the case-study chapters were written from, produced on
2026-10-14 by Claude Code research subagents (Sonnet 5.5) and checked by
the controller (Opus 5.5). They are factual and evidence-linked rather
than polished; where a chapter and a note disagree, the chapter (written
later, with more context) wins.

| File | What it is |
|---|---|
| `history-timeline.md` | Every commit with time, model, task, size |
| `history-requests.md` | Every partner request in order, quoted from the spec/plan, cross-checked with the raw prompts |
| `history-qwen-council.md` | Every council record Qwen wrote, and which later proved wrong |
| `history-stats.md` | Commit, line, test and timing numbers (as of commit `81887b4`, mid-way through the Claude pass) |
| `history-observations.md` | Neutral observations from the history |
| `opencode-environment.md` | The opencode setup: provider, plugins, skills, agents (secrets redacted) |
| `opencode-sessions.md` | Session-level numbers from the opencode database |
| `opencode-behaviors.md` | Notable model behaviours with short quotes (redacted) |
| `shots-manifest.md` | How the historical screenshots were taken |

Sanitized for a public repo: home-directory paths shortened to `~`, temp
paths removed, one private name omitted, credentials never copied.
